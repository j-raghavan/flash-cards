# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-07

## Context

The project will make many technical choices (scheduler, stack, hosting, auth). Future contributors need to know why.

## Decision

Record each significant decision as a short ADR in `docs/adr/`, numbered sequentially, with Context, Decision and Consequences. Superseded ADRs stay in place and are marked as superseded.

## Consequences

Small overhead per decision; durable rationale for maintainers and self-hosters.
